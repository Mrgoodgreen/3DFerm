# 🌻 Ферма Арины (Arina's Farm)

3D фермерский тайкун для платформы **Яндекс Игры**. Юная фермерша Арина получает от бабушки маленький участок и превращает его в процветающую ферму: луг и коровник, курятник, сыроварня, сад и соковарня, овчарня и ткацкая мастерская, мельница и пекарня, пасека и большая ярмарка.

Дизайн-документ: [`docs/GDD.md`](docs/GDD.md).

## Возможности

- Жанр idle-arcade: Арина носит стопку предметов за спиной, кормит животных, забирает продукцию, выкладывает её на прилавки и собирает монеты с покупателей.
- 9 производственных цепочек, 13 видов предметов, 9 станций, 5 полей/садов, 9 прилавков.
- 56 открываемых зон: животные, поля, здания, прилавки, помощники, ярмарка и 6 украшений фермы (каждое даёт +5% к ценам).
- 16 нанимаемых помощников, которые сами носят сырьё и товары по тропинкам.
- 7 видов улучшений, 6 нарядов в гардеробе.
- Сюжет из 9 глав с диалогами и портретами персонажей, затем бесконечные «Заказы округи».
- Уровни фермы, офлайн-доход, ежедневный подарок.
- Вся графика и звук процедурные: никаких внешних ассетов, архив весит ~180 КБ.
- Локализация: русский, английский, турецкий (автоопределение через SDK).

## Интеграция с Яндекс Играми

| Требование | Реализация |
|---|---|
| Подключение SDK | `<script src="/sdk.js">` в `index.html`, `YaGames.init()` в `src/sdk.ts` |
| Готовность игры | `ysdk.features.LoadingAPI.ready()` после загрузки и первого кадра |
| Gameplay API | `GameplayAPI.start()/stop()` при паузах, диалогах, окнах, рекламе, сворачивании вкладки |
| Пауза платформы | подписка на `game_api_pause` / `game_api_resume` |
| Язык | `ysdk.environment.i18n.lang` → ru / en / tr |
| Сохранения | `player.setData` / `getData` (без запроса авторизации) + резервная копия в `localStorage` |
| Полноэкранная реклама | только в паузах (после окна уровня/главы), не чаще раза в 150 с, с предупреждением |
| Видео за награду | только по нажатию игрока: ×2 доход, быстрые ноги, подарок, ×2/×3 награды, наряд |
| Звук | выключается при сворачивании вкладки и во время рекламы |
| Покупки | `getPayments()` → каталог; кнопка магазина появляется, только если товары настроены |
| Браузерные жесты | отключены скролл, выделение, контекстное меню, pinch-zoom, double-tap zoom |

### Товары для покупок (необязательно)

Если в консоли разработчика включены покупки, создайте товары с такими ID:

| ID | Что даёт |
|---|---|
| `coins_small` | +5 000 монет (расходуемый) |
| `coins_medium` | +30 000 монет (расходуемый) |
| `coins_big` | +150 000 монет (расходуемый) |
| `no_ads` | отключает полноэкранную рекламу (постоянный) |

Без настроенного каталога магазин в игре просто не показывается.

## Разработка

```bash
npm install
npm run dev        # локальный сервер (SDK заменяется заглушкой)
npm run typecheck
npm run build      # сборка в dist/
npm run zip        # сборка + arina-farm-yandex.zip для загрузки в консоль
```

При локальном запуске `/sdk.js` недоступен — игра работает без SDK, а видео за награду в режиме разработки выдаются сразу (чтобы можно было проверить награды).

Загрузите `arina-farm-yandex.zip` в [консоль разработчика Яндекс Игр](https://yandex.ru/games/console/) — `index.html` лежит в корне архива, все пути относительные.

## Структура

```
src/
  main.ts            загрузка: SDK → язык → сохранение → игра
  sdk.ts             обёртка над Yandex Games SDK
  data.ts            весь игровой контент и баланс
  i18n.ts            тексты ru / en / tr
  audio.ts           процедурная музыка и звуки (WebAudio)
  state.ts           формат сохранения
  input.ts           джойстик / клавиатура / мышь
  render/            сцена, процедурные модели, остров, портреты
  game/              игровая логика: поля, станции, прилавки, площадки, помощники, покупатели
  ui/                HUD, окна, диалоги
docs/GDD.md          дизайн-документ
```
